# Code of conduct

Sightline follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). In short: be welcoming and respectful, assume good intent, accept constructive feedback gracefully, and focus on what is best for the people who use and build Sightline. Harassment, insults and personal attacks are not accepted, in any form, anywhere in this project.

## Reporting

If someone's behavior in this project is a problem, tell the maintainers privately: open the [Security tab](https://github.com/ravindu-rev/sightline/security), choose **Report a vulnerability**, and say that it is about conduct. Only the maintainers can see these reports. Every report is reviewed and kept confidential.

The maintainers decide on the response, which can range from a private warning to a ban from the project, following the Contributor Covenant's enforcement guidelines.
